# AI TRPG Core

## Ollama routing

Single PCではPRIMARYだけを設定する。SECONDARY未設定時はJudgeもPRIMARYを使用する。

```text
PRIMARY_OLLAMA_URL=http://127.0.0.1:11434
SECONDARY_OLLAMA_URL=
SECONDARY_FAILURE_POLICY=FAIL_CLOSED
EXECUTION_PROFILE=SINGLE_PC
```

Dual PCでは、PL/KPをPRIMARY、LLM JudgeをSECONDARYへ送る。学校固有IPは環境変数または非公開の`src/.streamlit/secrets.toml`だけに設定する。

```text
PRIMARY_OLLAMA_URL=http://127.0.0.1:11434
SECONDARY_OLLAMA_URL=http://SECONDARY_HOST:11434
SECONDARY_FAILURE_POLICY=FAIL_CLOSED
EXECUTION_PROFILE=SCHOOL_DUAL_PC
```

旧`LLM_BASE_URL`、`OLLAMA_URL`、`OLLAMA_BASE_URL`、`OPENAI_BASE_URL`もPRIMARY設定として利用できる。優先順位は`PRIMARY_OLLAMA_URL`が最上位である。
