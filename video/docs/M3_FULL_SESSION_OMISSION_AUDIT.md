# M3 全セッション描写省略監査

監査日: 2026-10-12  
対象プロジェクト: `projects/corbitt_clear_001`  
対象: `normalized_session.json` 678イベント、`edited_script.json` 425行、全53シーン

## 結論

サンプル動画で見えたSANチェック前後の説明不足以外にも、省略または因果関係が崩れている箇所がある。最も重大なのは終盤戦闘である。コービット戦の構造化ログ自体は存在するが、本文が空のまま別シーンへ配置され、動画用台本では「起き上がる」から「戦闘終了」へ飛んでいる。

M2のCUT判定が重要な物語イベントを誤って削除した形跡はない。問題の中心は、セッション本文と構造化イベントログの同期、イベント内に混在した描写と数値の分離、ならびにM3での表示順である。

## 監査範囲

- 実際に再生成・動画QAされたM3プレビューは `scene_047_script_017` から `scene_048_script_013` まで。
- M2の編集結果とM3の `visual_plan.json` は全425行を含む。
- サンプル外については台本・構造化ログ・表示計画まで監査した。全編の音声生成、レンダー、Human Reviewはまだ行われていない。

## 重大な省略・因果関係の欠落

### 1. ナイフ出現からSANチェックまでの原因描写が遅い

対象: `scene_048_script_005`〜`009`

実際の順序は次の通り。

1. 目星失敗
2. `yes`
3. 幸運9点消費、成功へ変更
4. ナイフが手を振りほどき、宙に浮いて攻撃
5. SANチェック成功、減少0
6. KPがナイフの浮遊・血痕・恐怖を描写

動画では4が長いSYSTEM結果の中に埋まり、6がSANチェックの後に来る。したがって視聴者にはSANチェックの原因が先に提示されない。描写そのものは完全消失していないが、表示順のため実質的に省略された状態である。

### 2. ナイフの「攻撃結果」が存在しない

`trigger_knife_attack` は構造化ログで `false → true` になり、本文にも「攻撃してきた」とある。しかし、その後に攻撃判定、防御、回避、ダメージ、回収、無力化のいずれも記録されていない。ログはそのまま壁板の調査へ進む。

これはM3だけでは補えない。元セッション側でイベント開始後の解決処理が欠けている。

### 3. ナイフの発見順が矛盾する

対象: `scene_048`

- `script_007`: ナイフを拾い、魔法のダガーと確定し、攻撃を受ける。
- `script_017`: `junk_searched` 未達のためナイフは操作できない、と表示される。
- `script_030`〜`031`: ガラクタから改めて古びたナイフを発見する。

つまり「取得・正体判明・襲撃」の後に「まだ操作不能」「初めて発見」が来る。省略よりも重い時系列破綻で、サンプル後半まで含めて動画化すると顕在化する。

### 4. 地下室の扉が開いた／閉じているの双方で描写される

対象: `scene_047_script_007`〜`008`

SYSTEM側は「地下室への扉を開けた」「冷気とカビの匂いが漂う」と記録する一方、直後のKPは「依然として厳重に閉ざされている」と説明する。どちらを正史として扱うかが確定していないため、片方を省略するだけでは直らない。

### 5. コービット最終戦の実行過程が動画用台本から抜けている

セッション本文側の `scene_052` は次の順序で終わる。

1. コービットが起き上がり戦闘開始
2. PCが通常調査を続けようとする
3. `[Combat Director]` が戦闘外行動を拒否
4. 次の `scene_053` で突然「戦闘終了」「呪い解除」

一方、構造化ログには次の事実がある。

- 戦闘ID `combat-71-2483` を開始
- PC1の通常行動を拒否
- SYSTEM_GUIDEDで `break / corbitt_body` を選択
- `SPECIAL_OBJECTIVE` を `scenario_condition` で解決
- 戦闘終了条件を受理し、戦闘を終了

しかし、この6件は本文が `null` のまま `scene_025`〜`027` に配置されており、時系列上も終盤と同期していない。M2はOVERLAY_ONLYとして保持したが、表示文字がないため動画では見えない。

戦闘の「攻防」が省略されたというより、現行システムは戦闘を一回の特殊目標 `break` で解決している。その判断、行動、結果を視聴者向けの描写へ変換できていない。

### 6. エンディングが曖昧な一文だけで、音声もない

対象: `scene_053_script_001`

内容は「渾身の一撃、あるいは浄化の儀式によって」と二つの可能性を併記しており、実際に何をしたかを確定していない。さらにSUBTITLE_ONLYで、直後のKPエピローグもない。

構造化ログ上の実態は `break / corbitt_body` による特殊目標達成なので、その事実に基づく決着描写が必要である。

## サンプル外で残る会話文脈の欠落

全編には単独の `yes` が13件ある。現行のSYSTEM interaction resolverを全425行へ仮適用すると9件は文脈を復元できるが、次の4件は未解決のまま残る。

- `scene_037_script_005`: プッシュ見送り
- `scene_037_script_024`: プッシュ見送り
- `scene_038_script_013`: プッシュ見送り
- `scene_047_script_015`: プッシュ見送り

4件とも実際には「プッシュしない」という返答であるが、入力語は `yes`。結果ログの表現が `【プッシュ見送り】` のため、現在の暗黙確認判定が拾わない。全編をレンダーすると、質問なしの `yes` が残る可能性がある。

## 表示されると物語を阻害する内部情報

全425行には次の内部メッセージがKEEPされたまま残る。

- `Action Availability`: 22行
- `試行権消費済み`: 8行
- 重複した`進行指示`: 21行
- `システムブロック`: 1行
- `[Combat Director]`: 1行（VOICED）

これらは「描写の省略」とは逆に、内部制御文が物語描写の代わりに出る問題である。特にコービット戦でCombat Directorが音声化されると、クライマックスを壊す。

## M2で安全に省略されているもの

M2は678イベント中251イベントをCUTしている。

- unified event log由来: 206件。テレメトリ、状態遷移、重複構造化イベントが中心。
- session log由来: 45件。検証エラー、再生成失敗、進行通知、内部ヒント、戦闘外行動拒否が中心。

M2 QA上は、保護対象イベントの消失0、重大な連続性エラー0である。日記の発見、隠し通路、コービット覚醒などの主要描写は、SYSTEM結果の直後にKPが言い直しており、内容は保たれている。

ただし、強制移動4件は内部理由がCUTされている。移動自体と到着後のKP描写は残るため場所は追えるが、「探索者がなぜその場所を選んだか」という主体性は失われる。

## 省略ではなく正常に補完されている代表例

- `scene_047_script_004`〜`005`: コービットの日記3冊、オカルト実験、《彼方への道を切り開くものの招請》はKP音声で再説明される。
- `scene_048_script_011`〜`012`: 壁板の奥の空間と通路開通はKP音声で再説明される。
- `scene_052_script_001`〜`002`: コービットの目が動き、遺体が起き上がる描写はKP音声で再説明される。
- LOCATION_CHANGEは46行あるが、主要な移動後にはKPの到着描写が続く。

## 優先順位

1. **最終戦同期の修復**: structured combat eventsを `scene_052` に同期し、`break / corbitt_body` の選択と解決を描写へ変換する。
2. **ナイフイベントの原系修復**: 攻撃開始後に解決処理を追加し、ナイフ発見条件とイベント順を一本化する。
3. **因果順の保証**: `脅威の描写 → SANチェック → SAN結果 → 反応` の順でPresentationを組む。
4. **全編SYSTEM interaction適用**: 13件すべてを監査し、プッシュ見送り4件を含めて質問と返答の意味を明示する。
5. **内部文のPresentation除外**: Action Availability、試行権、Combat Directorを通常会話から除外する。
6. **決着とエピローグ追加**: 実際の `break / corbitt_body` に基づく一意な決着描写をKP音声で出す。

## 判定

サンプルのSAN問題だけを直しても、全編動画は成立しない。現時点の最大の阻害要因は字幕Rendererではなく、終盤イベントの時系列同期と、戦闘解決を物語描写へ変換する層の不足である。M3は引き続き `PRESENTATION_NEEDS_ITERATION` が妥当である。
